## Selected work

### ⚖️ [AI Fairness Auditor](https://github.com/Krispymarty/bias-detection-system)

An API for auditing high-stakes ML decisions in lending and hiring. It evaluates intersectional demographic groups, explains individual outcomes with SHAP, detects protected-attribute influence, and applies Fairlearn mitigation without retraining the baseline model.

- Evaluates fairness across **12 Gender × Age × Income groups**
- Reduced the documented selection-rate gap from **46.4% to 3.7%** while retaining ROC-AUC in the project evaluation
- Built with Python, XGBoost, FastAPI, Fairlearn, SHAP, and Pydantic
- Includes comparison endpoints, human-review confidence warnings, and counterfactual recommendations

### 🛡️ [Sentinel AI](https://github.com/Krispymarty/CyberShield)

## How I approach projects

1. **Choose a problem worth solving.** I start with the user, decision, or workflow that needs to improve.
2. **Build the complete path.** Models, APIs, interfaces, data flows, and deployment considerations should connect.
3. **Interrogate the result.** I look for bias, weak assumptions, edge cases, and the trade-offs behind the numbers.
4. **Leave useful evidence.** Documentation, limitations, and lessons learned are part of the project—not an afterthought.
